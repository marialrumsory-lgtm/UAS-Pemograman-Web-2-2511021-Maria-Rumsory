# Fitur gambar sampul

1. Salin isi folder ini ke proyek Rak-buku-digital, timpa file yang sama.
2. Terminal di folder proyek:
   php artisan migrate
   php artisan storage:link
3. Pastikan di .env: APP_URL=http://127.0.0.1:8000  (atau http://rak-buku-digital.test jika memakai Laragon)
4. Muat ulang situs, lalu Ubah data pada sebuah buku dan unggah gambar sampulnya.
